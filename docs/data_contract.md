# 输入输出与对账约定

## 原回测输入

`trades.csv` 必须包含交易编号、发起及申请时间、CREATE／REDEEM 方向、申赎单位倍数、ETF 份数、PCF 路径及原净盈亏。编号唯一。缺失的最终净盈亏仍然留空，不将待交收当结清。

`signals.csv` 用发起时间对应的原 IOPV 作为篮子分母；个股信号价格只使用当分钟或允许的一分钟前价格，不用未来价格填补。限价触价判断则要求对应分钟精确收盘价。

`orders.csv` 的 MANAGER 订单决定原回测是否对该股使用现金代理；PCF 必须现金替代项单独按固定现金处理。分析器不因触价自行选择新的替代股票。

`fills.csv` 按交易编号和证券代码索引一次。代理费从其 fee 字段读取，并在存在 fees.csv 时交叉核对 MANAGER／cash_substitution 记录的 total，防止缺费或重复扣费。

`substitution_pricing.csv` 中的 quantity × price 是原回测对未成交数量的期限估值，不把它计入实际成交股数或收取成交费用。

`trade_attribution.csv` 是原现金替代价格盈亏、E/A 和本金收付的核对基准。完整可定价的个股现金贡献之和与原金额偏差超过 0.000001 元时立即失败。缺基准／缺最终定价时标记 incomplete。

## 数据覆盖

`signal_status` 要求信号时刻精确分钟价；`before_signal_touched` 表示截至该信号时（含）曾经触价；`day_touched` 是全天事后描述。未知保留空值，不能当作未触价。无涨跌幅限制与未知是不同状态。

每日研究限价由 PreTradingDay 精确 15:00 收盘和当日 PCF 名称／代码推算；行情日期不按星期或自然日补造。触价区间不跨缺失分钟或午休合并。正式每日限价文件可覆盖研究推算，`--official-only` 禁用推算。

同一股票同一天在多笔申赎中会有不同信号权重和贡献。交易×股票记录数、去重股票日数、套利笔数分开统计。日级事件输出按 ETF、日期和股票去重。

## 对接原项目

分析器与原项目不互相 import 策略模块。`run` 命令在原项目目录调用其 CLI，写入全新的回测输出，再读取完成的结果产生分析；原回测报错时不会生成成功的分析报告。原 CLI 不支持单方向参数时提前提示。

`analyze` 和 `latest` 可单独运行，不需要重跑历史。生成目录必须为空，并且必须位于原始行情／PCF 目录之外。分析前后检查原运行文件的大小和修改时间，原文件发生变化时失败。真实样本校验还会额外核对逐笔金额。

## 规则资料

- [深交所：如何计算涨跌幅限制价格](https://investor.szse.cn/knowledge/stock/deal/t20180801_553961.html)：前收盘价、比例与最小价格单位取整规则。
- [深交所：2023 年交易规则](https://docs.static.szse.cn/www/lawrules/rule/allrules/bussiness/W020230217564423808793.pdf)：历史规则参考；不能替代逐日特殊状态数据。
- [上交所科创板投教问答](https://edu.sse.com.cn/tib/qa/)：上市初期无涨跌幅限制等例外。

这些资料解释推算的基本形式，不证明程序覆盖了所有日期和个股的特殊状态。真实每日上下限应优先使用有明确来源的逐日数据。
