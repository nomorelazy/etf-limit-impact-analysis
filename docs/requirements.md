# 涨跌停、ETF 权重与现金替代盈亏分析基线

2026-11-06，用户要求新建独立 GitHub 项目，复用既有 ETF／股票分钟数据和 PCF，
联系股票涨跌停、其在 ETF 中的成分股比例和申购／赎回后的现金替代盈亏；
每次回测完成后能够查看涨跌停股票的股数、权重和对应盈亏。

1. 独立项目读取原回测 config.json、trades.csv、signals.csv、fills.csv、fees.csv、
   cash_settlements.csv、substitution_pricing.csv、trade_attribution.csv，原目录只读。
2. 按本笔申请日 PCF 和单位倍数确定成分股股数，不将 ETF 份数当作股票数量。
   金额权重使用信号时成分股估值／本笔信号 IOPV 对应的篮子金额；不是简单的股数占比。
   PCF 固定现金项按原回测口径，不重复计算 159900 汇总行。
3. 信号当分钟触价、申请分钟触价、信号前已触价、申请日全天曾触价分开。
   全天结果是事后描述，不能伪装成信号已知；分钟缺失时不跨缺口合并连续触价区间。
4. 提供逐日正式限价 CSV 接口。只有 time／thscode／close 时，按 PCF PreTradingDay
   精确 15:00 收盘和当日 PCF 名称／代码板块推算研究限价；不借用未来收盘、未知前收盘、
   复权价格或固定百分比假装官方限价。上市初期、除权、临时调整等必须依赖正式限价表。
   不从触价推断封单、禁止买卖或自动改变原回测现金替代选择。
5. 对现金代理股票，申购贡献＝信号基准－实际替代成本（含代理费），赎回反向。
   实际成交、未成交期限估值、固定替代金额分别取原输出；未定价保留空值。
   逐股贡献之和必须与原现金替代价格盈亏一致，超出容差时报告失败。
6. 原回测中仍以实物买卖的触价股票，不捏造现金替代盈亏；另列实物价格影响。
   现金替代退补／应收本金不是利润；整篮 E/A 影响单独列示，不作个股因果分摊。
7. 涨跌停与盈亏的统计为条件关联／归因，不等同于“涨跌停导致”的因果估计。
   同一股票在多笔交易出现可分别归因；日级事件只算一次，不能把交易次数当事件天数。
8. 输出逐笔摘要、全部股票贡献、触价股票明细、股票汇总、权重分组和 HTML。
   回测＋分析包装命令仅生成新输出，保留原策略、交收和待结清处理。
9. 默认仓库为私有，仅上传源代码、合成测试样本及文档；真实行情和报告留在本地。
